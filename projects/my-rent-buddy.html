My Rent Buddy Website

A database-driven car rental web application supporting administrator and renter workflows with practical business rules.

Project Overview

My Rent Buddy is a PHP and MySQL-based car rental website built around two user roles: Administrator and Renter. The application connects frontend interfaces to backend rental records, return dates, vehicle status, and cost notifications.

Core Features

  • User registration and login
  • Vehicle search and listing pages
  • Rental processing and return handling
  • Admin dashboard and status updates

My Contribution

I designed relational database tables, implemented role-based workflows, connected interface actions to backend logic, and applied structured development practices to keep the solution maintainable.
